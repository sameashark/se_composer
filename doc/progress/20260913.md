# 2026-09-13

v2 公開後の機能追加とUI整頓。音源コア（engine.js）の音は変えていない。

## 今回やったこと

### 機能追加
- **再生カーソル**（PianoRoll）。`requestAnimationFrame` から DOM の `transform` を直接書き換える。
  毎フレーム state を更新すると再描画が走るため。位置は `AudioContext.currentTime` 基準
- **パラメータのリセット**（`reset` ボタン）。パラメータだけ初期値に戻し、ノートは残す
- **プリセットリストへのマージ**（`リストに追加`）。末尾に追加、同名は `名前 (2)` にリネーム
- プリセットファイルの解析・検証・マージを `src/presetFile.ts` に集約

### 直したこと
- 再生カーソルが `DELAY_TIME`（0.25秒）分ずれて見えていた。原音もディレイラインを通るため、
  譜面時刻のまま走らせるとノートの頭で音が鳴っていない。カーソル側で補正した
- **「リスト読み込み」で一覧が更新されないバグ**。`loaded.length <= 1 && current` のとき
  「単体プリセットは現在値として開く」と判断してリストを更新せず return していた。
  件数によらず必ず置き換えるよう修正
- `history` が無く `current` だけのファイルが拒否されていた
- `<button>` がフォントを継承せず、メニュー内で label と書体が食い違っていた
- プリセット選択時のトーストを削除（手元のリスト操作なので通知不要）
- JSON 読み込み時の自動再生を停止（`applySnapshot` の第3引数で制御）

### UI
- ツールバーをピアノロールの上に移動し、右詰めに配置。
  ピアノロールから下は音を作る操作だけにした
- JSON 操作4つを `データ▼` ドロップダウンに集約（`<select>` では
  アイコンやファイル入力を置けないため自前実装。外側クリックと Esc で閉じる）
- `iconButton` の padding を 8→4px に詰めてアイコンを 16→18px に拡大（矢印の向きが読めなかった）
- hover を全ボタンに付与（opacity 0.75）。canvas のノートは `globalAlpha` で同等に
- body に地色、`:root` に `color-scheme: dark`

## 判断に迷った箇所

- **JSON操作ボタンの配置**：単体DLとリスト操作が別の行に分かれていて散らかっていた。
  単体DLを削る案も出たが、リスト全体JSON（`{current, history}`）は CLI が読めず
  `sounds/*.json` を更新する手段が無くなるため却下。ユーザー提案のドロップダウン集約を採用
- **マージ時の同名衝突**：上書きだと件数が期待どおり増えず元データも消えるため、リネームを選択
- **`looksLikePreset` による検証**：`normalizePreset` が何でも受け入れてしまい、無関係な JSON から
  デフォルト値だけのプリセットが黙って生成されるため必要と判断した
- **原音をディレイに通さない案**：音は素直になり遅延も消えるが、既存プリセットの聞こえ方が
  変わるので手を付けていない（保留）
