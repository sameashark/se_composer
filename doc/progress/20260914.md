### 2. ピアノロールのノート選択・移動・コピー

ジェスチャを `pending` / `resize` / `marquee` / `move` の4状態に整理した。
**mousedown では何も確定せず、3px 動いた時点でどれかに決める。**
以前は mousedown で即ノートを置いていたため、空きセルからの範囲選択と同じジェスチャになっていた。

| 起点 | 動かさず離す | 動かす |
|---|---|---|
| 空きセル | ノート追加＋選択解除 | 範囲選択 |
| 未選択ノート | 単体選択 | 幅のリサイズ（従来どおり） |
| 選択済みノート | 単体選択に絞る | 選択全体を移動 |

`Ctrl+C` / `X` / `V` / `Delete` / `Escape`。移動中は store を触らず描画側でプレビューし、
mouseup で確定する。履歴は実際に動いたときだけ積む（リサイズも同様にしたので、掴んだだけで
`future` が飛ぶ既存の副作用が消えた）。タッチは従来のまま。

実装中に見つけて潰したもの:

- canvas の mousedown は `preventDefault()` でテキスト選択を止めているが、同時にフォーカス
  移動も止まる。数値欄にフォーカスが残ると `Ctrl+C` / `Del` が入力欄向けと判定されて効かない。
  mousedown で明示的に `blur()` する
- 右クリック削除や undo で消えたノートの id が選択に残り、件数表示がずれる

### 3. 事故防止（作業内容の自動保存）

- `current`（params と notes）を `se_composer_current` に 300ms デバウンスで自動保存し、
  起動時に復元する。以前はリロードで作業中の音が丸ごと消えていた
- **cut は「切って貼る」で一組**とみなし、切った中身を `pendingCut` として保存データに持たせ、
  起動時に譜面へ戻す。cut 以外でノートが動いたら確定して捨てる
- クリップボードも `se_composer_clipboard` に保存する
- undo 履歴は保存しない

### 4. UI 整理

- ピアノロール下に小さな文字で並べていた操作説明を `操作方法` のモーダルに畳んだ
  （`SHORTCUTS`）。常時出すのはステータス（選択件数・表示範囲外・♯表示）だけ
- 選択解除の出口を3つにした（`Esc` / 空白の右クリック / 「選択 N 件 ✕」ボタン）
- 「この音の書き出し」のツールチップから「CLI がそのまま読める形式」を削除。

## 判断に迷った箇所

### cut の巻き戻しをどう実現するか

最初は「クリップボードを localStorage に保存すれば、リロード後に `Ctrl+V` で戻せる」と考えた。
しかし求められていたのは **cut そのものをなかったことにする**ことだった。

`current` を自動保存すると cut 済みの状態が保存されるので、クリップボードが残っていても
譜面は戻らない。切った中身を保存データ側に `pendingCut` として持たせ、起動時に合流させる
方式に変えた。「cut を遅延削除にする（貼るまで内部では消さない）」案もあったが、画面と内部
状態が食い違う二重管理になるので採らなかった。

`pendingCut` を捨てる条件は「cut 以外でノートが動いたとき」。そのため store のノート操作が
すべて `pendingCut: []` を書き、cut だけが専用の `cutNotes` を通る。

### ノート移動のジェスチャ割り当て

「ノート右端をリサイズハンドルに、それ以外をドラッグで移動」という DAW 標準のほうが1ノートの
移動は速い。ただし幅1のノート（28px）ではハンドルが窮屈で、タッチでは実質使えない。
**未選択ノートのドラッグは従来どおりリサイズ**のままにして、既存の操作を壊さないほうを採った。
1ノートを動かすにはクリックで選択してからドラッグ、の2アクションになる。

### 音程を半音で数えるか、表示行で数えるか

移動と貼り付けの上下方向を、`ALL_PITCHES` の半音単位にするか、表示中の行にするかで迷った。
`♯ を表示` が off のときに半音単位で動かすと、マウスは白鍵の行を跨いでいるのにノートが
1半音しか動かず、見た目が追随しない。**表示中の行基準**にした。黒鍵に着地した場合は
`hasSharpNote` が立って♯の行が自動で出るので、ノートが消えることはない。

### canvas 外のクリックで選択解除するか

入れなかった。パラメータを触るたびに選択が外れると、選択したまま音を確認する使い方が
できなくなるため。
